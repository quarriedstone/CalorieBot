# Changelog

Все значимые изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии проекта следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- **Формат `название Б,Ж,У`** — Б/Ж/У сразу на съеденную порцию, без веса (например, `Экспонента 30 0 6.5`): калории считаются по 4/9/4, без обращения к API.
- **Продукт не найден** — если модель сообщила `found=false` (непищевой ввод, вроде «Москва», «Ыропа»), бот отвечает «Продукт не найден» и не добавляет запись в день.
- **Удаление продукта** — кнопка «🗑 Удалить продукт» в меню: бот показывает нумерованный список блюд активного дня, удаление — по кнопке с номером. Номера идут в обратном порядке (последняя запись — первой), на странице до 8 кнопок, остальные — за широкой кнопкой «Далее».
- **Удаление дня** — кнопка «🗑 Удалить день» на карточке дня: бот спрашивает подтверждение («✅ Удалить» / «❌ Отмена») и удаляет день вместе с записями; активный день при этом сбрасывается, а после удаления бот сообщает об этом и предлагает выбрать день заново из истории.
- **Блокировка до выбора дня** — пока день не выбран заново, бот не добавляет продукты и не открывает удаление продукта: в ответ приходит список дней из истории.

### Changed

- Название блюда при распознавании через DeepSeek берётся из ответа модели как есть (раньше переопределялось локально на «Название (вес г)»).
- Перешли на DeepSeek **Responses API** (`client.responses.create`) со строгой JSON-схемой ответа (`text.format` = `json_schema`); модель по умолчанию — `deepseek-flash` (было `deepseek-chat` через Chat Completions).
- В ответе модели появились `found`, `confidence` и `reason`: непищевые и неизвестные вводы больше не добавляются как блюдо.
- С карточки дня убрана inline-кнопка «📅 Новый день» — создание дня осталось только кнопкой в главном меню, а на карточке теперь «🗑 Удалить день».
- Кнопки главного меню переименованы: «📅 Новый день» → «📝 Новая заметка», «📜 История» → «📂 Выбрать заметку»; на карточке — «🗑 Удалить день» → «🗑 Удалить заметку».
- В текстах бота и документации сущность «день» переименована в «заметку»: «Заметка, открытая из истории, становится активной», «Последние заметки», «В этой заметке пока нечего удалять» и т. д.

### Removed

- Кнопка «↩️ Текущий день» на карточке дня и метод `DayService.back_to_today()` — заметка выбирается заново из списка, отдельный возврат к последней не нужен.

### Fixed

- Числа в скобках и через слэш («Экспонента (30/0/6,5)») разбираются локально в порядке Б/Ж/У — раньше такой ввод уходил в модель, которая могла переставить значения.
- Примеры продукта «Экспонента» в подсказках, промпте модели и документации пишутся с большой буквы.

## [0.1.0] - 2026-09-20

Первая рабочая версия бота.

### Added

- **Цель КБЖУ** — задаётся одним сообщением в виде `белки/жиры/углеводы` (например, `120/60/220`); калории считаются как Б×4 + Ж×9 + У×4. Разделители — `/`, пробел или запятая.
- **Добавление блюда** — запись добавляется в текущий день; КБЖУ либо считаются локально из указанного состава, либо подбираются через DeepSeek API.
- **Форматы ввода еды**:
  - `круассан 60` — 60 г продукта, КБЖУ подбирает DeepSeek под указанный вес;
  - `круассан 60 10,15,40` — Б/Ж/У **на 100 г**, пересчёт на указанный вес без обращения к API;
  - `овсянка на молоке, 300 ккал` — свободное описание, КБЖУ подбирает DeepSeek с учётом явно указанных калорий.
- **Таблица дня** — блюда и КБЖУ за день, остаток или превышение относительно цели.
- **Новый день** — кнопка «📅 Новый день» создаёт новый день, копируя сохранённую цель; за одну дату допустимо несколько дней.
- **История** — кнопка «📜 История» показывает последние 5 дней; выбранный день становится активным, возврат к текущему — кнопка «↩️ Текущий день».
- **Хранение данных** — SQLite (`aiosqlite`); миграция `users.active_day_id` для выбранного дня.
- **Архитектура** — разделение на слои `domain/`, `infrastructure/`, `presentation/`; DI-контейнер `dependency-injector`; инъекция сервисов в обработчики через `ContainerMiddleware`.
- **Интеграция с DeepSeek** через OpenAI-совместимый SDK.
- **Конфигурация** через переменные окружения (`.env`, `pydantic-settings`).
- **Docker** — `Dockerfile` и `docker-compose.yml`, данные в volume `bot_data`.
- **Инструменты разработки** — Ruff для линтинга и форматирования.
